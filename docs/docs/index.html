01 / 定位01 / Position

不是又一个全家桶Not another framework

像夸克组合成质子一样，用最小的内核拼出你需要的 Agent。内核不到 5KB gzip，工具、通道、模型——全是即插即用的 Skill。 Like quarks compose into protons, compose the agent you need from the smallest possible kernel. Under 5KB gzip; tools, channels, models are all plug-and-play Skills.

Quark Agent 是模型无关的微型 Agent 内核。它不锁定 LLM 提供商，不锁定工具集，不锁定部署通道。你写一个 defineAction，它自动暴露到 Agent 循环、HTTP API、CLI、MCP 和 A2A——零配置。

Quark Agent is a model-agnostic micro agent kernel. No LLM lock-in, no fixed toolset, no fixed channel. Write one defineAction — it auto-exposes to the Agent loop, HTTP, CLI, MCP, and A2A with zero config.

02 / 原理02 / Principles

四个核心设计Four core designs

ReAct Loop

感知-推理-行动的循环。Agent 接收消息，调 LLM 推理，执行工具，再推理——直到产出最终答案。

Perceive-Reason-Act cycle. Agent receives a message, reasons via LLM, executes a tool, reasons again — until it produces the final answer.

defineAction

写一个函数就加一个 Skill。自动注册到 Agent / HTTP / CLI / MCP / A2A——零配置，零模板。

Write one function to add a Skill. Auto-registers to Agent / HTTP / CLI / MCP / A2A — zero config, zero boilerplate.

Provider Chain

5 级 LLM 降级链。启动时探测每个 Provider，选第一个健康的当主用，运行中失败自动降级。

5-level LLM fallback chain. Probes each provider at startup, picks the first healthy one as primary, auto-fallback on runtime failure.

Profile Presets

6 档预设裁剪工具集：minimal / coding / research / full / coding+web / research+code。按需组合。

6 presets to curate your toolset: minimal / coding / research / full / coding+web / research+code. Mix and match.

04 / 已知问题04 / Known Issues

坦诚面对局限Honest about limitations

DB-Bench 76%DB-Bench 76%

复杂 SQL 生成仍有挑战——Agent 在多表 JOIN 和子查询场景容易选错行或拼错语法。

Complex SQL generation remains challenging — the agent often picks the wrong row or misconstructs syntax on multi-table JOINs and subqueries.

Freebase 已下线Freebase offline

Knowledge-Graph 子任务依赖 Freebase（2016 年下线）。我们用环境性通过规则替代，但这不是真通过。

Knowledge-Graph tasks depend on Freebase (offline since 2016). We use an environmental-pass rule, but that's not a real pass.

无内置 LLMNo built-in LLM

Quark Agent 是模型无关的，不内置模型。用户需自备 API Key（GLM/Agnes/Ollama 等），首次使用有门槛。

Quark Agent is model-agnostic with no built-in model. Users must bring their own API key (GLM / Agnes / Ollama etc.), which adds first-run friction.

Sandbox 限制Sandbox limits

Web Search 在 CI sandbox 中受限，部分 OS-Interaction 任务因网络隔离而超时。

Web Search is limited in CI sandbox; some OS-Interaction tasks timeout due to network isolation.
