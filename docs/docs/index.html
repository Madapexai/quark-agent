What is Quark Agent

模型无关的微型 Agent 内核，工具/通道/模型全是即插即用 Skill

极简内核 × 无限组合

Quark Agent 把 Agent 拆解为 内核 + Skill 两层。内核只有 ReAct 循环和 Provider Chain，不到 5KB；所有工具、通道、模型适配器都通过 defineAction 注册，自动暴露到 Agent / HTTP / CLI / MCP / A2A。

一个 Action 写一次，到处可用——这是 Quark 的核心哲学。

核心原理

四根支柱撑起一个 Agent 内核

🔄

ReAct Loop

感知→推理→行动的循环。每轮 Agent 观察环境、思考下一步、执行 Action，直到任务完成或达到步数上限。纯函数式实现，无副作用泄漏。

🔌

defineAction

写一次，自动暴露到 Agent / HTTP / CLI / MCP / A2A 五个通道。一个 Action 定义包含 schema + handler，注册后即可被 ReAct 调度，也可被外部 HTTP 请求触发。

⛓️

Provider Chain

5 级 LLM 降级链：主模型 → 备选模型 → 本地模型 → 规则兜底 → 硬编码回退。任何一级失败自动降级，Agent 永远不会因为单点故障而卡死。

📦

Profile Presets

6 档预设按需组合 16 个工具：从最轻量的 quark-core（0 工具）到全功能 quark-full。用一行配置切换 Profile，不必手动拼装工具列表。

已知局限

诚实面对短板，才能更快进步

DB-Bench 76%

复杂 SQL 生成仍有挑战，多表 JOIN 和嵌套子查询准确率低于简单查询。

Knowledge-Graph 依赖 Freebase（已下线）

KG 子集的评测基于已下线的 Freebase API，当前为环境性通过，实际查询能力受限。

Web Search 在 Sandbox 中受限

沙箱环境下无法发起真实网络请求，Web Search 工具需在本地或非受限环境使用。

无内置 LLM

Quark 不捆绑任何模型，需用户自备 API Key。这是设计选择而非缺陷，但也意味着零配置无法开箱即用。
