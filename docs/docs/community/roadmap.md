# Roadmap

What's done and what's coming.

## Done

- [x] 5KB kernel + 16 composable tools
- [x] 7 channels (CLI / HTTP / Feishu / WeCom / Telegram / GitHub / Webhook)
- [x] A2A protocol (agent-to-agent)
- [x] GEPA self-evolution
- [x] 200-task benchmark suite (AgentBench + GAIA) at 89.0% pass rate
- [x] Bilingual README (English + Simplified Chinese)
- [x] Interactive HTML benchmark report
- [x] Issue / Discussion templates

## In Progress

- [ ] Standalone docs site (MkDocs Material on GitHub Pages)
- [ ] `npx quark-agent` one-line installer
- [ ] Animated demo GIF for README hero

## Planned

- [ ] Plugin marketplace (`quark-agent add @someone/slack-skill`)
- [ ] Multimodal computer-use tool (Claude Computer Use style)
- [ ] Discord channel
- [ ] Slack channel
- [ ] Streaming function-call benchmark (τ-bench style)
- [ ] SWE-bench subset for code engineering tasks
- [ ] Local model adapters (Ollama, llama.cpp) with first-class support
- [ ] Web UI v2 with task timeline visualization

## Long-term

- [ ] Browser-use agent (Playwright-backed)

- [ ] Self-hosted eval dashboard
